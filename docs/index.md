# Crible docs

Crible (French: "sieve") is a bias-correcting product-research agent: a
single-user, on-demand agent that distils the truth from lived experience and
delivers an auditable, source-backed recommendation — including *why* products
were rejected — instead of amplifying marketing/SEO/affiliate bias.

**Status:** MVP implemented (single-threaded). See the
[README](../README.md) for the full project overview, install & run
instructions, principles, and roadmap; this `docs/` tree holds the structured
handbook material and does not replace it.
